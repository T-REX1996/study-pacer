# study-pacer

[English](./README.en.md) | 日本語

参考書や問題集の**ページ数を、締め切りから逆算**して、1日あたりのページ数に振り分けるライブラリ兼 CLI です。

> ページ数のある教材(紙の本、問題集、ページ数のある電子書籍など)向けです。ページの概念がない動画や Web ページの学習計画には向きません。CLI の表示は日本語のみです。

「あと何ページを、何日で終わらせるか」を、休みの日も考えて計算します。遅れたときは、残りのページで割り直せます。

## 特徴

- 休みの曜日(日曜など)や、休みの日付を除いて振り分ける
- 割り切れないときは、前半の日に 1 ページずつ多く割り当てる(後半に余裕が残る)
- 終えたページを引いて、途中から立て直せる
- 依存パッケージなし(Node.js 22 以上)
- ライブラリとしても、CLI としても使える

## インストール

```sh
# ライブラリとして使う
npm install study-pacer

# CLI をどこからでも使う
npm install -g study-pacer

# インストールせずに試す
npx study-pacer 100 --to 2026-11-08 --rest 日
```

## CLI の使い方

```sh
study-pacer <総ページ数> --to <締め切り日> [オプション]
```

たとえば、100 ページの問題集を、11 月 2 日(月)から 8 日(日)までに終わらせたいとき、日曜を休みにするには、次のようにします。

```sh
study-pacer 100 --from 2026-11-02 --to 2026-11-08 --rest 日
```

```text

勉強する日 6日(休み 1日)、1日 16〜17ページ

11/02(月)   17ページ  累計  17
11/03(火)   17ページ  累計  34
11/04(水)   17ページ  累計  51
11/05(木)   17ページ  累計  68
11/06(金)   16ページ  累計  84
11/07(土)   16ページ  累計 100
11/08(日)  休み
```

### 遅れたときは、割り直す

11 月 5 日の時点で 60 ページまで進んでいたら、`--from` に今日の日付を、`--done` に終えたページ数を渡します。

```sh
study-pacer 100 --from 2026-11-05 --to 2026-11-08 --rest 日 --done 60
```

```text
全100ページ(終えた分 60ページ、残り 40ページ)
勉強する日 3日(休み 1日)、1日 13〜14ページ

11/05(木)   14ページ  累計  74
11/06(金)   13ページ  累計  87
11/07(土)   13ページ  累計 100
11/08(日)  休み
```

### 休みを複数指定する

`--rest` と `--rest-date` は、同じオプションを何度でも並べて指定できます。次の例では、日曜と水曜(`--rest` を 2 回)に加えて、11 月 10 日と 12 日(`--rest-date` を 2 回)も休みにしています。

```sh
study-pacer 100 --from 2026-11-02 --to 2026-11-15 \
  --rest 日 --rest 水 \
  --rest-date 2026-11-10 --rest-date 2026-11-12
```

### オプション

| オプション           | 説明                                                            |
| -------------------- | --------------------------------------------------------------- |
| `--to <日付>`        | 締め切り日(`YYYY-MM-DD`)。必須                                  |
| `--from <日付>`      | 開始日(`YYYY-MM-DD`)。省略すると今日                            |
| `--done <ページ数>`  | 終えたページ数。省略すると 0                                    |
| `--rest <曜日>`      | 休みの曜日(`sun`〜`sat`、または `日`〜`土`)。何度でも指定できる |
| `--rest-date <日付>` | 休みの日付(`YYYY-MM-DD`)。何度でも指定できる                    |
| `-h`, `--help`       | 使い方を表示する                                                |

入力に誤りがあるときは、エラーメッセージを表示して、終了コード 1 で終わります。

## ライブラリの使い方

ES Modules 形式です。`import` で読み込んでください。

```js
import { planStudy, formatPlan } from 'study-pacer'

const plan = planStudy({
  totalPages: 100,
  startDate: '2026-11-02',
  deadline: '2026-11-08',
  restWeekdays: ['sun'],
})

console.log(plan.perDay) // 17(多い日のページ数)
console.log(plan.studyDays) // 6
console.log(formatPlan(plan)) // CLI と同じ表示の文字列
```

### `planStudy(options)`

| オプション     | 型                        | 説明                                                                  |
| -------------- | ------------------------- | --------------------------------------------------------------------- |
| `totalPages`   | `number`                  | 総ページ数(1 以上の整数)。必須                                        |
| `startDate`    | `string`                  | 開始日(`YYYY-MM-DD`)。必須                                            |
| `deadline`     | `string`                  | 締め切り日(`YYYY-MM-DD`)。開始日と同じか、後の日。必須                |
| `restWeekdays` | `Array<string \| number>` | 休みの曜日。`'sun'`、`'日'`、`0`(日曜)〜`6`(土曜)のどれでも指定できる |
| `restDates`    | `string[]`                | 休みの日付(`YYYY-MM-DD`)                                              |
| `donePages`    | `number`                  | 終えたページ数。省略すると 0                                          |

戻り値は、次のとおりです。

| プロパティ       | 説明                                                           |
| ---------------- | -------------------------------------------------------------- |
| `totalPages`     | 総ページ数                                                     |
| `donePages`      | 終えたページ数(総ページ数を超える指定は、総ページ数にそろえる) |
| `remainingPages` | 残りのページ数                                                 |
| `studyDays`      | 勉強する日の数                                                 |
| `restDays`       | 休みの日の数                                                   |
| `perDay`         | 1 日あたりのページ数(多い日の分)                               |
| `completed`      | すべて終わっていれば `true`                                    |
| `days`           | 日ごとの計画の配列                                             |

`days` の各要素は、次のとおりです。

```js
{
  date: '2026-11-02', // 日付
  weekday: 'mon', // 曜日(sun〜sat)
  rest: false, // 休みの日なら true
  pages: 17, // その日に進めるページ数(休みの日は 0)
  cumulative: 17, // その日が終わった時点の累計ページ数(終えた分を含む)
}
```

### `formatPlan(plan)`

`planStudy()` の結果を、ターミナルに表示する日本語の文字列にします。

## ルール

- 日付は `YYYY-MM-DD` の形式です。存在しない日付(`2026-02-30` など)はエラーになります。
- 締め切り日も、勉強する日に含めます。
- 日付の計算は UTC で行うので、タイムゾーンや夏時間の影響を受けません。CLI で `--from` を省略したときだけ、実行している環境の今日の日付を使います。
- 期間は 3660 日(約 10 年)以内です。
- 入力に誤りがあるときは、`TypeError`(形式の誤り)または `RangeError`(値の誤り)を投げます。メッセージは日本語です。
- 勉強できる日が 0 日(すべて休み)のときはエラーです。ただし、すべて終えている場合は、エラーにならず `completed: true` で返します。
